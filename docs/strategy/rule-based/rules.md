# Rule

A rule simply combines a `Condition` and an `Action` into one entity. Upon a `Condition` being true, when the rule is evaluated, an `Action` will be executed. This essentially allows you to create a rule that does whatever you need it to - enter a long intent upon an indicator reaching a threshold, selling upon a custom source giving a signal, etc.
