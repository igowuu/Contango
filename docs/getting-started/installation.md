# Installation

**Requires Python 3.10+ & git**

## Open a terminal and clone the repository:

**Windows/Linux/macOS**
```bash
git clone https://github.com/igowuu/Contango.git
```

## Change into the project directory:

**Windows/Linux/macOS**

```bash
cd Contango
```

## Create a virtual environment:

**Windows**
```bash
python -m venv .venv
```

**Linux/macOS**
```bash
python3 -m venv .venv
```

## Activate your virtual environment:

**Windows**
```bash
.venv\Scripts\activate
```

**Linux/macOS**
```bash
source .venv/bin/activate
```

## Install required packages (in the root directory):

**Windows/Linux/macOS**
```bash
pip install -r requirements.txt
```

## Next steps

Once installed, head to [Quickstart](./quickstart.md) to backtest & analyze your first strategy.
